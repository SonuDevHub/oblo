# NAMING.md — Naming Conventions

**Principle:** a file's name must tell what it does. Someone should know the file's job without opening it.

## Code
| Thing | Convention | Example |
|---|---|---|
| Files & folders | `kebab-case`, verb/noun that says the job | `ride-offer-form.tsx`, `create-server-client.ts` |
| React components | `PascalCase` | `RideCard`, `FareBreakdownCard` |
| Functions / variables | `camelCase`, verb first | `getSeatsLeft`, `submitRideOffer` |
| Booleans | `is/has/can` prefix | `isFull`, `canRequest`, `hasRequested` |
| Constants | `UPPER_SNAKE` | `MAX_SEATS = 6` |
| Types / interfaces | `PascalCase` | `RideWithSeats`, `RequestStatus` |
| Hooks | `use-…` file, `useX` export | `use-ride-realtime.ts` → `useRideRealtime` |
| Server actions | `<verb><Entity>Action` | `createRideAction` |
| Zod schemas | `<entity><Purpose>Schema` | `rideOfferSchema` |

## Database
| Thing | Convention | Example |
|---|---|---|
| Tables | `snake_case`, plural | `rides`, `ride_requests` |
| Columns | `snake_case` | `total_seats`, `ride_date` |
| FKs | `<entity>_id` | `owner_id`, `pickup_stop_id` |
| Views | `v_` prefix | `v_rides_with_seats` |
| Functions | `verb_noun` | `request_seat`, `respond_to_request` |
| Admin functions | `admin_` prefix | `admin_set_user_blocked` |
| Indexes | `idx_<table>_<cols>` | `idx_requests_ride_status` |
| Policies | plain English | `"students read active rides"` |
| Migrations | `NNNN_<what_it_does>.sql` | `0003_create_seat_rpc_functions.sql` |

## Docs & reports
- Docs: `UPPER_SNAKE.md` in `docs/`.
- Reports: `reports/PHASE-<N>-<slug>-report.md` e.g. `PHASE-3-seat-requests-report.md`.
- Branches: `feat/<area>-<short>`, `fix/<area>-<short>`.
